## Overview

Clinkast is a digital platform connecting healthcare professionals and patients, built to streamline medical appointment booking and teleconsultation services in Cameroon. I joined the early engineering team and contributed across the full stack during a critical growth phase.

## Projects I Worked On

### Patient-Facing Booking Interface
Built and iterated on the patient-facing web interface for discovering healthcare providers, viewing availability, and booking appointments. Focused on clean UX and responsive layout across devices.

### Teleconsultation Module
Contributed to the development of the video consultation feature, integrating a WebRTC-based solution and building the surrounding UI — session management, waiting room, and post-consultation feedback flow.

### Provider Dashboard
Developed features for the provider (doctor/clinic) dashboard including appointment calendar management, patient history views, and profile configuration.

### Backend API Features
Implemented REST API endpoints for appointment management, user profiles, and notification triggering. Worked with the existing Node.js backend and contributed to schema design and data layer logic.

## My Contributions

- Delivered full-stack features across both Vue.js frontend and Node.js backend
- Collaborated closely with design to implement pixel-accurate responsive interfaces
- Participated in code reviews and contributed to improving code quality standards
- Wrote unit tests for critical business logic flows
- Helped triage and resolve production bugs reported by early users

## Value I Brought

Contributed to shipping a functional healthcare platform during a period where speed of delivery was critical. My full-stack capability meant I could take a feature from backend schema to polished frontend independently, reducing handoff delays and enabling faster iteration. This role solidified my approach to product-focused engineering.
