## Overview

KAMIX is a fintech company operating in Central Africa, focused on simplifying money transfers and financial services for the African diaspora and local users. The engineering team was responsible for building secure, reliable backend services to support the product.

I joined as the lead backend developer and owned the architecture and implementation of core backend systems.

## Projects I Worked On

### Money Transfer API
Built and maintained the core transfer API responsible for routing payments between users and partners. Handled transaction lifecycle management including initiation, validation, fee calculation, partner routing, and status tracking.

### User Account & KYC System
Developed the user registration, authentication, and KYC (Know Your Customer) verification flow. Integrated with external identity verification providers and built internal admin tooling to review and approve user documents.

### Partner Integration Layer
Designed and implemented an abstraction layer for connecting with external payment partners and mobile money operators. The layer standardized communication across different partner APIs and provided retry logic, error handling, and logging.

### Internal Admin Dashboard API
Built the REST API powering the internal admin interface used by the operations team to manage users, transactions, disputes, and partner configurations.

### Notification Service
Implemented a notification service to deliver SMS, email, and push notifications to users across the transaction lifecycle using a queue-based architecture.

## My Contributions

- Led backend architecture and implementation across core product features
- Defined API contracts and collaborated with the frontend team on integration
- Introduced and enforced API design standards and backend coding conventions
- Wrote and maintained API documentation
- Reviewed pull requests and mentored junior backend developers
- Monitored production systems and resolved incidents

## Value I Brought

Delivered a reliable and scalable backend foundation for a fintech product operating in a demanding, real-money environment. Reduced transaction error rates by introducing proper validation and retry logic. Enabled the product team to ship features faster by building well-documented, modular APIs that the frontend could consume independently.
